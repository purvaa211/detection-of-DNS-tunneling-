Project Overview & Data Variables

Using DNS telemetry as a practical dataset for probability and statistics

This project applies core Probability and Statistics syllabus concepts to real-world network query data. Rather than focusing on complex cybersecurity protocols, we analyze two continuous random variables extracted from domain names:

  • Shannon Entropy ($H$): Measures the character randomness in bits per character. Normal domain names (e.g., google.com, wikipedia.org) have natural English patterns with lower entropy ($\sim 2.0 - 3.4$ bits). Encoded or suspicious queries (e.g., a7f9b0c1e8...attacker.com) have high randomness ($\sim 4.0 - 4.9$ bits).
  • Inter-Arrival Time ($\Delta t$): Measures the time gap between consecutive queries. Normal human browsing is variable and bursty, whereas automated scripts often send rapid or regular queries.

Two-Sample Hypothesis Testing (Welch's t-Test)

Comparing Normal vs Suspicious traffic means without assuming equal variances
Formal Statistical Hypotheses:
• Null Hypothesis ($H_0$): $\mu_{\text{normal}} = \mu_{\text{suspicious}}$ (There is no true difference in population means between normal and suspicious traffic).
• Alternative Hypothesis ($H_1$): $\mu_{\text{normal}} \neq \mu_{\text{suspicious}}$ (There is a statistically significant difference between the two traffic groups).

Viva Explanation for Examiners

Because the calculated p-value is extremely small ($p < 0.001$), it is far below the significance threshold $\alpha = 0.05$. Therefore, we reject the null hypothesis $H_0$. This provides rigorous mathematical evidence that the higher entropy and longer query lengths observed in suspicious traffic are statistically genuine and not a product of random chance.

Type I Error (False Positive, α)
Rejecting $H_0$ when it is actually true. In this context: falsely flagging legitimate users as suspicious, causing unnecessary disruption.
Type II Error (False Negative, β)
Failing to reject $H_0$ when an actual difference exists. In this context: failing to detect suspicious traffic, leaving the network vulnerable.
