Two-Sample Hypothesis Testing (Welch's t-Test)

Evaluating whether the difference in means between Normal and Suspicious traffic is statistically significant
Formal Statistical Hypotheses:
• Null Hypothesis (H0): Mean value is equal between Normal and Suspicious traffic.
• Alternative Hypothesis (H1): Mean value is significantly different between Normal and Suspicious traffic.

Statistical Conclusion:
Because the calculated p-value is extremely small (p < 0.0001), it is far below the significance threshold alpha = 0.05. Therefore, we reject the null hypothesis (H0). This provides rigorous statistical evidence that the higher entropy and longer query lengths observed in suspicious traffic are statistically genuine differences and not random variation.
Type I Error (False Positive, alpha)

Rejecting the null hypothesis when it is actually true (falsely accusing legitimate normal traffic of having anomalous characteristics).

Type II Error (False Negative, beta)

Failing to reject the null hypothesis when an actual difference exists (failing to flag genuine tunneling traffic).

Project Findings & Statistical Conclusion:
• Linear Relationship & Payload Randomness: Domain query length and Shannon entropy demonstrate a strong, statistically significant linear relationship (R² > 86%). Because data exfiltration via DNS tunnels encodes arbitrary binary or base32/hex payloads into subdomains, queries simultaneously become longer and exhibit elevated character entropy.
• Hypothesis Testing Rejection: Across both Shannon entropy and query length, Welch's two-sample t-test yields p < 0.0001, decisively rejecting the null hypothesis (H0) and proving that normal traffic and suspicious queries follow distinctly different population distributions.
• Syllabus Method Effectiveness: By applying descriptive statistics, Bayes' theorem, normal confidence intervals, and linear regression, we successfully distinguish suspicious tunneling activity using pure, interpretable statistical mathematics without needing black-box machine learning models.
