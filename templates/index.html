Project Abstract & Domain Context

Applying statistical modeling to detect encoded data channels

DNS Tunneling encodes unauthorized data into domain name queries (e.g. a7f9b0c1.tunnel.attack.com) to bypass network security controls. Rather than relying on rigid signature matching, this course project evaluates two fundamental statistical properties:

  • Shannon Entropy ($H$): Encoded or encrypted payload characters exhibit high informational randomness ($H \approx 4.0 - 5.0$ bits/char) compared to natural language domain names ($H \approx 2.0 - 3.4$ bits/char).
  • Timing & Burst Regularity ($\Delta t$): Automated tools or periodic beacons exhibit unnaturally fast or regular arrival rates compared to human web browsing.

Exponential Distribution: Inter-Arrival Times (IAT)

Testing the memoryless arrival property: f(t) = λ e^(-λt) for normal vs suspicious traffic

Concept note: If network events arrive as an independent Poisson process with rate $\lambda$, their inter-arrival times are Exponentially distributed. Legitimate web requests approximate this exponential decay, whereas automated tunneling tools or periodic C2 beacons violate memorylessness by concentrating arrivals in tight periodic clusters.

Type I Error (False Positive, α)
Rejecting the null hypothesis when it is actually true. In this context: falsely concluding that legitimate DNS traffic has different statistical characteristics, leading to false alarms on harmless web users.
Type II Error (False Negative, β)
Failing to reject the null hypothesis when an actual difference exists. In this context: failing to detect active DNS tunneling and exfiltration because the statistical test was underpowered or the threshold was too conservative.
